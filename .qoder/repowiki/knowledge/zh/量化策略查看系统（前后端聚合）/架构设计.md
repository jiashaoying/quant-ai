仓库以三个并列子项目构成：backend/ 提供 FastAPI HTTP API（端口 8000），frontend/ 提供 React + Vite 开发服务器（端口 3000），wiki-site/ 基于 MkDocs Material 编译静态文档站；三者之间无代码依赖，仅通过 HTTP 接口耦合——前端调用后端 /api/backtest、/api/market、/api/strategies 等路由，Wiki 独立构建。根目录的 start.sh/start.bat 负责并行拉起后端 uvicorn 与前端 npm dev，Makefile 统一封装 install-deps、check-backend（pytest）、check-frontend（tsc --noEmit）、wiki、wiki-serve 等跨子模块命令，其中 wiki 构建复用 backend/venv 中的 mkdocs-material，体现后端虚拟环境对 Wiki 的隐式共享。

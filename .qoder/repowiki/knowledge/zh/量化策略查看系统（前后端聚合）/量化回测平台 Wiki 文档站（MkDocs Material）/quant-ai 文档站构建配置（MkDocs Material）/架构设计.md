模块由四个文件构成最小化的文档站流水线：
- `build.py` 是入口脚本，提供 `all / links / prepare / config / build / postprocess` 五种模式，按顺序执行：① `fix_file_links` 把 Markdown 中的 `file://...#Lx-Ly` 引用转为相对路径；② `prepare_docs` 在 `../.qoder/repowiki/zh/content` 下注入首页 `index.md` 与 `stylesheets/extra.css`（避免被 Qoder 同步清理）；③ `generate_mkdocs_config` 扫描 content 目录树递归生成 `mkdocs.yml` 的 `nav` 层级（节索引页置首，优先页面 `项目概述/快速开始/回测系统` 置顶）；④ `build_site` 通过 `subprocess.run([sys.executable, '-m', 'mkdocs', 'build'])` 调用 mkdocs；⑤ `post_process_site` 遍历 `site/*.html`，将指向仓库源码的相对链接重写为 `https://gitcode.com/jiashaoying/quant-ai/blob/main/...`。
- `mkdocs.yml` 是被 `build.py` 覆盖生成的配置文件（顶部注释明确禁止手工编辑），定义 material 主题、中文语言、Mermaid 自定义 fence、search 插件及导航树。
- `extra.css` 提供 `<cite>` 区块样式，构建时被复制到 content/stylesheets 下供 MkDocs 引用。
- `requirements.txt` 仅声明 `mkdocs>=1.6.1` 与 `mkdocs-material>=9.5`，无 Python 业务依赖。
依赖方向单向：`build.py` → MkDocs CLI → 产物 `site/`，不反向依赖站点代码。

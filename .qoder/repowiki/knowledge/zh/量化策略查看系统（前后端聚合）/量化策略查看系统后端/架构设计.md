后端采用分层装配模式：`main.py` 启动 FastAPI 应用并挂载三个子路由（/api/strategies、/api/backtest、/api/market），每个路由模块对应一个业务子模块；跨层依赖方向自上而下为 api_routes → services_data_source / backtest_strategy_engine → db_models_core。
- 配置由 `app.core.config.settings`（pydantic-settings）集中注入，被 API 路由与回测引擎共享读取。
- 数据获取统一经 `services.data_source_manager.DataSourceManager` 在腾讯财经/yfinance/AKShare/BaoStock/模拟数据之间按可用性回退，对上层隐藏具体来源差异。
- 持久化通过 `db.database.get_engine/get_session` 暴露 SQLAlchemy 会话，`models.models` 定义策略与回测结果 ORM，供回测执行后落库。
- 测试位于 `tests/`，使用 pytest + conftest 直接实例化 engine 与服务进行单元测试。

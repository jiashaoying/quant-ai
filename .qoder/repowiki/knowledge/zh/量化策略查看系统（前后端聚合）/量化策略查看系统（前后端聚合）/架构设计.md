根目录作为编排层，不承载业务逻辑，仅负责把 backend（FastAPI + 策略引擎 + 多源数据服务）与 frontend（React + Vite）两个独立子项目装配在一起：
- 运行时由 start.sh / start.bat 在单进程内并行拉起 uvicorn（localhost:8000）与 npm dev（localhost:3000），并统一捕获 Ctrl+C 终止两个子进程。
- 开发验证由 Makefile 的 check 目标串联 pytest（backend）与 tsc --noEmit（frontend）。
- 前后端通过 HTTP REST 接口解耦，前端调用 http://localhost:8000 下的策略列表与回测 API，无共享代码或包依赖；跨子模块的约定集中在 QUICKSTART.md 中声明（端口、数据源枚举、新增策略/数据源的步骤）。

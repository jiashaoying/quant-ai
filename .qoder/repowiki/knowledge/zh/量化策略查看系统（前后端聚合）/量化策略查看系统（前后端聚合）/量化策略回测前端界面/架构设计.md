模块为典型的单页 React 应用：入口 `src/main.tsx` 通过 `ReactDOM.createRoot` 挂载 `<App />`；`src/App.tsx` 作为根组件维护全局状态（选中策略、回测结果、加载态），并通过 props 将状态下沉到三个子组件——`StrategyList`（策略选择）、`BacktestForm`（回测参数表单）和 `BacktestResult`（结果可视化）。所有业务逻辑集中在 App 层，子组件以无状态 UI 为主。HTTP 调用直接使用原生 `fetch` 请求 `/api/backtest/run`，由 Vite dev server (`vite.config.ts`) 代理到后端 `http://localhost:8000`。样式采用 CSS Modules 风格（每个 `.tsx` 对应同名 `.css`），图标统一来自 `lucide-react`。

# quant-ai 项目文档

欢迎来到**股票量化策略查看与回测系统**的 Repo Wiki 文档站。

本系统提供 8 种内置量化策略、5 个数据源（含智能降级）与完整的回测引擎，前端 React 可视化展示回测结果。

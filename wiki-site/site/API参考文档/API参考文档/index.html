    简介¶

    本API参考文档面向量化策略查看与回测系统的后端REST服务，覆盖三大能力域： - 策略管理：获取策略列表、获取策略详情 - 回测：执行回测、查询历史（预留） - 市场数据：获取股票行情、获取股票基本信息、搜索股票代码

    系统基于FastAPI构建，提供JSON格式的RESTful接口，默认启用CORS以支持前端跨域调用。当前版本为1.0.0。

    项目结构¶

    后端采用分层路由+服务+引擎的组织方式： - 路由层：按业务域划分策略、回测、市场数据三个Router - 服务层：封装数据源选择与统一的数据访问接口 - 引擎层：策略信号生成与回测计算 - 配置与模型：应用配置与数据库模型定义

    获取策略列表¶

    • 方法：GET
    • URL：/api/strategies/
    • 描述：返回系统内可用的策略清单及其参数元信息
    • 请求参数：无
    • 成功响应：数组，每项包含id、name、description、parameters
    • 失败响应：无特定错误码

    回测API¶

    执行回测¶

    • 方法：POST
    • URL：/api/backtest/run
    • 描述：根据策略与标的，拉取数据、生成信号并运行回测，返回绩效与明细
    • 请求体（JSON）：
    • strategy_id：字符串，必填
    • symbol：字符串，必填
    • start_date：字符串，可选，日期格式YYYY-MM-DD
    • end_date：字符串，可选，日期格式YYYY-MM-DD
    • period：字符串，默认"1y"
    • initial_capital：浮点数，默认100000.0
    • source：字符串，默认"auto"，可选值包括auto/yfinance/akshare/baostock/mock
    • parameters：对象，策略参数键值对
    • 成功响应：
    • metrics：对象，包含total_return、annual_return、max_drawdown、sharpe_ratio、win_rate、total_trades等
    • trades：数组，每笔交易的入场/出场价、盈亏、方向等
    • equity_curve：数组，时间序列资金曲线
    • signals_data：数组，信号与持仓变化序列
    • strategy：对象，包含id、name、parameters
    • symbol：字符串
    • data_source：字符串，实际使用的数据源
    • is_mock：布尔，是否使用模拟数据
    • 失败响应：
    • 400：请求参数错误或内部异常（detail中包含错误信息）

    示例 - curl - POST http://localhost:8000/api/backtest/run - Content-Type: application/json - Body: { "strategy_id": "ma_cross", "symbol": "AAPL", "start_date": "2023-01-01", "end_date": "2023-12-31", "period": "1y", "initial_capital": 100000, "source": "auto", "parameters": {"short_window": 5, "long_window": 20} } - JavaScript - fetch('/api/backtest/run', { method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify({ strategy_id: 'ma_cross', symbol: 'AAPL', start_date: '2023-01-01', end_date: '2023-12-31', period: '1y', initial_capital: 100000, source: 'auto', parameters: { short_window: 5, long_window: 20 } }) }) .then(r => { if (!r.ok) throw new Error(r.statusText); return r.json(); }) .then(console.log);

    性能与限制¶

    • 回测计算复杂度：
    • 信号生成：O(n)，n为数据条数
    • 回测引擎：O(n)遍历计算收益与指标
    • 数据获取：
    • 外部数据源可能受网络与配额限制；建议使用缓存或批量拉取
    • 并发与限流：
    • 当前未实现限流；在高并发场景下建议增加网关级限流与队列化任务
    • 序列化开销：
    • 大量K线与资金曲线数据会增大响应体积；可考虑分页或压缩传输

    故障排查指南¶

    • 常见错误与处理
    • 400 Bad Request：回测请求参数错误或数据获取失败。检查strategy_id、symbol、日期格式与数值范围
    • 404 Not Found：策略不存在。确认策略ID是否在策略列表中
    • 数据为空或NaN：检查数据源可用性、symbol是否正确、日期区间是否有效
    • 调试建议
    • 使用浏览器开发者工具或Postman验证请求与响应
    • 先调用策略列表与市场数据接口，确认基础能力正常后再执行回测
    • 关注is_mock字段，若为true说明使用了模拟数据，需调整source或配置真实数据源
    • 日志与诊断
    • 开启DEBUG模式以便获得更详细的错误堆栈
    • 检查.env环境变量与数据库连接（如启用持久化）
